# 媒体界面设计约定

视觉采用中性深色表面和橙色强调，保持内容、封面和时间轴的优先级。导航、普通页面与播放覆盖层共享语义资源；透明播放浮层仍保持文字与按钮的可辨识度。

## 资源

Themes/MediaTokens.xaml 是颜色、字体、表面、圆角和基础内边距的统一来源。字体采用 Segoe UI 与 Microsoft YaHei UI 回退，正文 14、说明 12、分节 20、页标题 28；图标仍使用专用图标字体。Themes/MediaTheme.xaml 提供按钮、输入框、滑动开关、图标按钮及播放按钮模板；页面通过 DynamicResource 使用资源。保留原脚本热力图色谱，不把强度颜色改成装饰色。

## 布局

主页封面固定 16:9，标题单行省略，横向书架仅在溢出时响应滚轮。播放侧栏继续采用一列大封面。媒体库保留紧凑列表和封面卡片两种视图；筛选栏低于 600 宽时分行。播放栏按实际按钮与音量容量预留空间，优先保证播放、进度和设置入口。

## 交互

普通按钮至少 36 高，播放辅助按钮 40×40。Hover、Pressed、Disabled、Selected 和键盘焦点使用共享模板。次要功能进入内嵌菜单；左侧、右侧及底部覆盖层分别保留原独立显示逻辑。

## 设置与内嵌表单

采用 Windows 媒体应用的中性灰卡片：标题与说明在左，布尔开关在右。开关轨道 42×22，普通行至少 40 高，设置卡片至少 64 高，长标签允许换行；开启使用橙色，关闭使用中性灰。SettingsToggleSwitch、ToggleSwitch、CompactToggleSwitch 共用同一模板，分别服务卡片、普通表单与表格。

保留原 CheckBox 对象及绑定，通过模板呈现滑动开关，避免替换控件导致自动保存、三态、禁用依赖或键盘语义丢失。表格显示模式不响应点击，编辑模式才切换；TransportToggle 等播放图标按钮保留专用样式。

内嵌表单继承同一字体和表面。输入、按钮增高后，元数据、区间、时间偏移、设备及连接表单使用明确的 Auto 行；旧生成器布局转换仅限四个已识别生成器类，保留原控件与绑定。不对普通对话框做全局坐标重排。菜单与设置入口仍在现有播放器内部打开。

## 本轮检查项

| 维度 | 检查方法 |
| --- | --- |
| 视觉层级 | 封面与标题先于次要操作；空收藏不占位 |
| 字体 | 标题单行省略，长名称有悬停提示 |
| 色彩 | 共享中性表面和橙色交互资源 |
| 留白 | 统一按钮模板及卡片间距 |
| 一致性 | 主页、媒体库、播放栏与快捷浮层共享资源 |
| 内容密度 | 收藏限六项，完整命令收入更多 |
| 键盘 | 视图切换允许 Tab 焦点，焦点轮廓独立绘制 |
| 响应布局 | 920、1280、1920 窗口及窄筛选区域验证 |
| 状态反馈 | 空状态、选中视图与播放记录继续可见 |
| 性能 | 收藏更新合并；保留列表虚拟化与预览取消机制 |

这些是本轮的审查约定；不同 DPI、辅助技术和物理设备需要独立实机验证。

## 第二轮主题、语言和动效

设置入口：设置 → 操作与外观 → 界面与外观。语言、主题、强调色立即生效并自动保存；动画使用同一滑动开关。深色/浅色共用语义资源，强调色为橙、蓝、青绿、紫、玫红；浅色的强调色使用较深色值保证文字识别。

视频与全局播放栏保持深色透明叠加层和白色播放文字，页面主题不改变视频/热力图。设置组标题和页面标签允许换行，窄窗口通过分类下拉导航；最小窗口宽度 760，播放控件按实际剩余视口收起次要操作。

页面淡入 160ms，从 0.82 到 1，不移动页面、视频或命中区域。快速切页取消上一动画；关闭开关或系统关闭动画立即恢复完整不透明度。菜单淡入遵循同一开关。

新界面字面量须有中英文映射，绑定中的媒体名称、用户标签、路径和输入保持数据原值。统一字体/控件模板继续沿用 MediaTheme；不得用翻译重建连接选项或快捷键绑定。

## 时间轴与底边唤醒（v1.0.12.2）

标记层位于热力图上方，热力图紧接进度行；三者共用时间映射及左右内边距，不在热力图与进度之间保留额外标记行。播放热力图命中高度18、可见色条10，进度命中高度22并完整容纳原20直径滑块；迷你播放器保留原12高度热力图。

隐藏播放按钮时，热力图与标记仍可预览及Seek。它们下方保留真实12DIP底边唤醒区；悬停热力图或从视频靠近不会展开按钮，继续移至底边才展开。区域尺寸与实际留白同源；无热力图/标记也保留唤醒区，非播放页Compact不留空区。原拖动、菜单、焦点和暂停保持协议不变。

## 设备优先导航（v1.0.12.5）

主页设备卡片先于最近媒体。Handy、Wi-Fi、USB和蓝牙SPP/COM使用同一设置子页导航，管理设备为常驻子页。连接中的Wi-Fi操作暂时保留当前页，拒绝重复连接、断开或退出并恢复导航选中项。沿用共享主题及原密码框、设备开关与命令；不把发出连接请求或UDP发送端就绪显示为实物在线。蓝牙仅复用Windows传出COM，明确不包含BLE/GATT。

## 动画与性能（v1.0.12.6，取代早期160ms页面方案）

设置 → 操作与外观 → 动画与性能。新配置默认Light；Off全部停用，Light开启按钮、开关、底部与菜单反馈，Standard再开页面和调整面板，Custom逐项决定。编辑分项立即进入Custom并启用；Off保留分项值供恢复。封面仅短时明暗反馈，不放大封面。动态GIF独立配置，旧配置保留原有自动播放行为，新配置默认关闭。

MotionPresentation只管理WPF短时Opacity/RenderTransform时钟：按钮/封面90ms，开关/显现100ms，页面120ms，位移6DIP。取消使用当前元素归属检查，结束/卸载清除引用并恢复稳定值。隐藏立即Collapsed并停止命中；出现始于0.86，避免libmpv layered overlay完全透明时鼠标穿透。视频HwndHost、进度/热力图、布局列宽和设备链不动画化。

始终遵循Windows ClientAreaAnimation；最小化停用，窗口恢复后按原偏好显示。自动简化在render tier<2或两次自然完成超过目标时长160ms时关闭Page/Panel/Cover，不覆盖保存预设。不计取消/最小化为卡顿。无常驻Rendering事件或额外输出线程；GIF隐藏/卸载停用，预览关闭不取消后台帧加载。

设置保留原CheckBox及三态/键盘/禁用语义。圆点0/9/18用RenderTransform，按下不改变轨道/圆点尺寸；旧SettingsToggleSwitch转为透明分隔行。主页图标使用现有Segoe MDL2 Assets，连接含义/命令不变。
